🐛 COMMON ISSUES & SOLUTIONS:

CORS Error:
  → Backend missing CORS headers
  → Add: app.use(cors())

401 Unauthorized:
  → Invalid/expired token
  → Check JWT generation

404 Not Found:
  → Wrong endpoint URL
  → Verify URLs in .env match backend

TypeError on object property:
  → Different response structure
  → Compare with INTEGRACION_MICROSERVICIOS.md
